## ЛР №1. Типовые звенья и их динамические характеристики

Вариант: `W_оу(s) = 60/(0,2s+1)`, `W_иу(s) = 1/(s(0,25s+1))`.

- `lab1_plots.py` — строит 28 графиков (ВЧХ, МЧХ, АЧХ, ФЧХ, АФХ, ЛАЧХ, ЛФЧХ для ОУ, ИУ, разомкнутой и замкнутой системы) в `img/`
- `build_report.py` — собирает отчёт `Отчет_ЛР1_ТАУ_Ильин_Жеренков.docx`

```bash
python3 lab1_plots.py && python3 build_report.py
```

Нужны `numpy`, `matplotlib`, `python-docx`. Титульный лист берётся из `../лабы эвм/отчеты_ЛР1/`.
